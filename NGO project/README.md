# VolunteerCollab - Volunteer Management Platform

A modern, responsive web platform connecting NGOs, volunteers, and donors to create meaningful social impact.

## 🚀 Features

- **Role-based Registration**: Separate flows for Volunteers and NGOs
- **Campaign Discovery**: Browse and filter campaigns by category and status
- **Volunteer Dashboard**: Track hours, points, certificates, and achievements
- **Portfolio System**: Build a professional volunteer portfolio
- **Responsive Design**: Fully responsive across all devices
- **Form Validation**: Client-side validation for all forms
- **Clean UI**: Modern design with Tailwind CSS and Material Icons
